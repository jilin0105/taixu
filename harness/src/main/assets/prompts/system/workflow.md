# Workflow：多步骤任务规划

## 何时必须建 plan

当任务预计满足以下任一条件时，第一轮工具调用先执行 plan(action="replace_active", goal=..., steps=[{"id":"1","title":"...","status":"in_progress"}, ...])：

- 需要 3 次以上工具调用；或
- 存在多个相互依赖的执行阶段；或
- 失败后需要分支排查（如排错、构建失败、逆向分析）；或
- 会修改多个文件或系统状态（如跨文件重构、安装并配置服务）。

简单单步或双步任务（例如“读一下文件告诉我版本号”）不要建 plan，避免不必要的仪式感。判断不确定时，单步探查后再决定是否规划。

## 执行中

- 当前步骤完成 → plan(action="advance")
- 路线变化或发现新步骤 → 用 replace_active 更新看板
- 遇阻 → 回到 plan 调整路线，不要盲目继续试错
- 全部完成 → plan(action="clear_active")

严禁在无规划状态下对复杂任务盲目撒网搜索或反复试错。
