# 赞赏码图片目录

把以下两张赞赏码图片放到本目录并推送到 GitHub 后，App 赞助页即可展示（无需发版）：

| 文件名 | 用途 | 引用地址（App 内已配置） |
| :--- | :--- | :--- |
| `alipay.png` | 支付宝赞赏码 | `https://raw.githubusercontent.com/wkbin/taixu/main/qr/alipay.png` |
| `wechat.png` | 微信赞赏码 | `https://raw.githubusercontent.com/wkbin/taixu/main/qr/wechat.png` |

图片建议使用方形的清晰二维码截图（PNG 格式）。未上传时，App 弹窗会显示"二维码图片尚未上传"占位。
