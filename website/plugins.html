TAIXU PLUGIN GUIDE / 01

把你的工具，
装进太墟。

太墟插件是一个可验证、可回滚、面向 ARM64 Linux 用户态的工具包。用一个 .txplugin 文件，把命令、SDK、脚本或本地 Web 服务带进你的沙箱。

目录包格式清单字段Hello 示例打包与导入大型离线依赖发布检查

01 / 插件包格式

离线插件使用 ZIP 容器，文件扩展名为 .txplugin。ZIP 根目录必须直接包含 manifest.json 和 payload/，不能再多包一层目录。

hello-arm64.txplugin
├── manifest.json
└── payload/
    ├── archives/       # SDK、Gradle、Flutter 等大文件
    ├── scripts/        # 安装脚本或配置
    └── bin/            # ARM64 可执行文件

包内路径不允许绝对路径或 ..。大型依赖应随包携带，离线插件安装时不会替你再次下载。

02 / 编写 manifest.json

清单是插件的能力声明。当前 schema 为 1；应用会校验 id、架构、启动类型、权限和安装方式。

{
  "schemaVersion": 1,
  "id": "hello-arm64",
  "name": "Hello ARM64",
  "description": "TaiXu 本地插件示例",
  "version": "1.0.0",
  "publisher": "Your Name",
  "category": "DEVELOPER",
  "launchType": "command",
  "architectures": ["ARM64"],
  "permissions": [],
  "source": "LOCAL",
  "offlineOnly": true,
  "installMethod": "LOCAL_PACKAGE",
  "commandLinks": ["hello"],
  "verifyCommand": "hello"
}
字段作用
id稳定唯一标识，只能使用小写字母、数字和连字符。
launchTypecommand 命令行；pty 交互终端；web/service 后台服务。
architectures必须包含 ARM64，当前应用只支持 arm64-v8a。
permissions只申请实际需要的 NETWORK、WORKSPACE_READ、WORKSPACE_WRITE、LOCAL_WEB。
commandLinks暴露到 /opt/taixu/bin 的稳定命令入口。

03 / 从零制作 Hello 插件

创建以下目录，并将脚本放在 payload/bin/hello：

hello-arm64/
├── manifest.json
└── payload/bin/hello

脚本内容：

#!/bin/sh
echo "hello from TaiXu"

在安装步骤中再次设置执行权限，避免 Windows 打包时丢失 Unix 执行位：

"installSteps": [
  "test -f "$TAIXU_PLUGIN_PAYLOAD/bin/hello"",
  "mkdir -p "$TAIXU_TOOL_DIR/bin"",
  "cp "$TAIXU_PLUGIN_PAYLOAD/bin/hello" "$TAIXU_TOOL_DIR/bin/hello"",
  "chmod +x "$TAIXU_TOOL_DIR/bin/hello""
]

04 / 打包与导入

Windows PowerShell

Compress-Archive -Path .\hello-arm64\manifest.json, .\hello-arm64\payload -DestinationPath .\hello-arm64.txplugin -Force

Linux / macOS

cd hello-arm64
zip -r ../hello-arm64.txplugin manifest.json payload

在太墟中打开“设置 → 插件与工具中心”，点击文件导入，选择 .txplugin，然后安装并等待 verifyCommand 通过。

05 / 大型离线依赖

Flutter、Android SDK、Gradle、NDK 等依赖放在 payload/archives/，安装脚本只能通过 $TAIXU_PLUGIN_PAYLOAD 读取。

set -eu
archive="$TAIXU_PLUGIN_PAYLOAD/archives/flutter-arm64.tar.xz"
test -s "$archive"
echo "<SHA256>  $archive" | sha256sum -c -
rm -rf /opt/flutter.staging
mkdir -p /opt/flutter.staging
tar -xJf "$archive" -C /opt/flutter.staging
test -x /opt/flutter.staging/flutter/bin/flutter

不要把 x86_64 工具伪装成 ARM64。对 ELF 文件执行 readelf -h 检查 AArch64，对归档执行 SHA-256 校验。

06 / 发布前检查

  • ZIP 根目录只有 manifest.json 与 payload/。
  • 全新安装、重复安装、升级和卸载都通过。
  • 断网可以完成安装、验证和启动。
  • 命令链接、PTY / Web 服务和日志均正常。
  • 没有 ../、绝对路径、RootFS 外路径或未声明权限。
